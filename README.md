## 🚀 Quick Start

### 1. Get Your API Key

Visit [console.anthropic.com](https://console.anthropic.com) to:
1. Create an account
2. Generate an API key
3. Set it as an environment variable:

```bash
export ANTHROPIC_API_KEY='your-api-key-here'
```

### 2. Install Dependencies

**Python:**
```bash
pip install anthropic
```

**Node.js:**
```bash
npm install @anthropic-ai/sdk
```

### 3. Run Examples

**Python:**
```bash
python claude_integration_examples.py
```

**JavaScript:**
```bash
node claude_integration_examples.js
```

## 🎬 Features

### AI-Powered Capabilities

- **Customer Support Chatbot** - Intelligent assistant for customer inquiries
- **Review Analysis** - Automated sentiment analysis and insights from reviews
- **Movie Recommendations** - Personalized suggestions based on user preferences
- **Content Generation** - Automated movie descriptions and marketing content
- **Social Media Posts** - Generate engaging posts for different platforms

### Supported Claude Models

- **Claude Opus 4.5** (`claude-opus-4-20250514`) - Most powerful, best for complex tasks
- **Claude Sonnet 4.5** (`claude-sonnet-4-20250514`) - Balanced performance and cost
- **Claude Haiku** (`claude-haiku-4-20250115`) - Fastest, for simple tasks
